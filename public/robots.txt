#    - Update sitemaps when adding new properties
#    - Use XML sitemap format (not HTML)
#
# 5. TESTING:
#    - Test with Google Search Console > Coverage > Blocked by robots.txt
#    - Verify important pages are NOT blocked
#    - Monitor crawl stats in Search Console
